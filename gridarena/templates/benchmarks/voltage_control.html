Submission Script Format

The script must define a function predict. It is called once per test snapshot (a grid at a timestamp with at least one voltage violation):

def predict(snapshot):
    # snapshot = {
    #     "datetime": "2025-07-01T13:00:00", "scenario": "Overvoltages",
    #     "voltage_limit": 241.5, "nominal_voltage": 230.0, "voltage_band": 0.05,
    #     "measurements": [
    #         {"node_id": "NODE0001", "phase": "R", "power_active": 3.2,
    #          "power_reactive": 0.4, "voltage_magnitude": 247.9, "voltage_angle": -0.6},
    #         ...
    #     ],
    # }
    return [{"node_id": "NODE0001", "phase": "R", "corrected_voltage": 241.0,
             "adjusted_power_active": 2.1, "adjusted_power_reactive": 0.4}, ...]

The actions use the same format as the reference solutions of the training data. A node and phase you don't return is scored as left unchanged. Per snapshot, the score rewards matching the reference corrected voltages (within 1 V) and then the least change in active power; snapshots without a reference are scored on how far the voltages move back towards nominal. The overall score (0–1, higher is better) is the node-weighted mean over all snapshots. Code at module level runs once before the first call, so load model weights there. The script has no network access and can use the packages installed on the server (numpy, pandas, scipy, torch, ...).
