Submission Script Format

The script must define a function predict. It is called once per test grid with every node of the grid (random keys), the substation node and the measurements of the metered nodes:

def predict(grid):
    # grid = {
    #     "nodes": ["3f9c1a2b7d4e", "a07be3c95f11", ...],
    #     "root": "a07be3c95f11",              # substation, or None
    #     "measurements": {
    #         "3f9c1a2b7d4e": [
    #             {"datetime": "2025-01-01T00:00:00", "phase": "R",
    #              "power_active": 1.24, "power_reactive": 0.08,
    #              "voltage_magnitude": 229.7, "voltage_angle": -0.42},
    #             ...
    #         ],
    #         ...
    #     },
    # }
    return [["a07be3c95f11", "3f9c1a2b7d4e"], ...]   # the grid's edges

Edges are undirected; pairs with an unknown key or the same key twice are ignored. The score is the F1 of your edges against the true ones (precision and recall are reported too), so wrong extra edges cost as much as missed ones. Code at module level runs once before the first call, so load model weights there. The script has no network access and can use the packages installed on the server (numpy, pandas, scipy, networkx, torch, ...).

See API Docs to submit from code: POST /topology_discovery_benchmark/submissions.
