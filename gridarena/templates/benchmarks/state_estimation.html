Submission Script Format

The script must define a function predict. It is called once per estimation task: a test grid at one timestamp, where some series (one per node and phase, random keys) are measured and the others must be estimated:

def predict(task):
    # task = {
    #     "timestamp": "2025-01-01T12:00:00",
    #     "known": {"3f9c1a2b7d": {"power_active": 1.24, "power_reactive": 0.08,
    #                              "voltage_magnitude": 229.7, "voltage_angle": -0.42}, ...},
    #     "unknown": ["a07be3c95f", ...],
    #     "history": {"3f9c1a2b7d": [{"datetime": ..., "power_active": ..., ...}, ...], ...},
    # }
    return {"a07be3c95f": {"voltage_magnitude": 228.9, "voltage_angle": -121.3}, ...}

Return an estimate for every unknown series: a missing or non-numeric one is scored as 0 V with the worst angle. The score is mean (ΔV)² + mean |sin(Δθ)| over all unknown series of all tasks (lower is better); the RMSE of the voltage magnitude and the MAE of the angle are reported too. Every submission with the same settings gets exactly the same tasks. Code at module level runs once before the first call, so load model weights there. The script has no network access and can use the packages installed on the server (numpy, pandas, scipy, torch, ...).

See API Docs to submit from code: POST /state_estimation_benchmark/submissions.
